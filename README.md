# Interpolation matrices and jumping lines of logarithmic bundles

## Description

This repository contains the file `code.txt` with code written in **Singular** (version **4.4.1**), accompanying the paper:

**Elena Guardo, Graham Keiper, Grzegorz Malara**  
*Interpolation matrices and jumping lines of logarithmic bundles*

The code provides procedures for computing the **interpolation matrices** introduced and studied in the paper. It also includes predefined parameters corresponding to the **examples discussed in the article**, allowing the reader to reproduce and experiment with the presented computations.

## Requirements

- **Singular**, version **4.4.1**

## Usage

Load the file `code.txt` into Singular and execute the procedures.  
The parameters for the examples considered in the article are already set in the code and can be modified if needed.

## Files

- [`code.txt`](code.txt) — Singular code containing procedures for computing interpolation matrices and parameter settings for the examples from the paper.
